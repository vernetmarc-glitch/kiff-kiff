Ce téléphone

Vaut pour le jeu ouvert dans ce même navigateur (sur Android, l’appli installée aussi). Ouvrir kiff-kiff.fr/?compte=non fait pareil, ?compte=oui annule. Sur iPhone, l’appli installée sur l’écran d’accueil garde ses propres réglages.

Connexion

Ces deux réglages restent dans ce navigateur. L’adresse doit aussi être mise dans config.js pour que les téléphones envoient leurs comptes.

Mise en place, une seule fois

  1. Sur un ordinateur, va sur script.google.com › Nouveau projet, connecté à ton compte Google. Nomme-le « Kiff Kiff ».
  2. Efface le code présent et colle celui-ci :
  3. Enregistrer (icône disquette). Puis roue dentée Paramètres du projet › Propriétés du script › Ajouter une propriété : nom motdepasse, valeur : ton mot de passe › Enregistrer. Il reste là, jamais dans le code.
  4. Dans la liste des fonctions en haut, choisis preparer, puis Exécuter. Google demande l’autorisation : Examiner les autorisations › ton compte › Paramètres avancés › Accéder à Kiff Kiff (non sécurisé) › Autoriser. La feuille « Kiff Kiff — données » apparaît dans ton Drive.
  5. Déployer › Nouveau déploiement, roue dentée › Application Web. Exécuter en tant que : moi. Qui a accès : Tout le monde. Puis Déployer.
  6. Copie l’adresse de l’application Web (elle finit par /exec), colle-la ci-dessus avec ton mot de passe, puis Vérifier.
  7. Va dans Les mots et touche Enregistrer dans l’appli : la feuille reçoit la liste actuelle.

Les téléphones envoient des comptes anonymes, sans prénom, sans texte écrit à la main et sans identifiant : ouverture du jeu, partie lancée (un ou deux téléphones, piments choisis), envie proposée, « Oui, mais… », kiff kiff (et le temps pour le premier), « on passe », invitation créée ou rejointe, montée de piment acceptée ou non, partages, clics café, installation ; pour une envie, le mot de chaque roue. Pour les parties à deux téléphones, la feuille garde aussi la dernière étape de chaque partie, chiffrée par les téléphones : illisible dans la feuille, même pour toi.

Mettre à jour le script

Quand le code du script change (par exemple pour les parties à distance), sans changer d’adresse :

  1. Sur script.google.com, ouvre le projet « Kiff Kiff ».
  2. Efface tout le code et colle le nouveau (bouton Copier le code ci-dessus).
  3. Enregistrer (icône disquette). Le mot de passe ne bouge pas : il est dans les propriétés du script.
  4. Déployer › Gérer les déploiements, crayon (Modifier), Version : Nouvelle version, puis Déployer. L’adresse reste la même.
