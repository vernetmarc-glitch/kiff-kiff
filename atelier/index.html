Connexion

Ces deux réglages restent dans ce navigateur. L’adresse doit aussi être mise dans config.js pour que les téléphones envoient leurs comptes.

Mise en place, une seule fois

  1. Ouvre une nouvelle feuille Google Sheets (sheets.new) et nomme-la « Kiff Kiff — données ».
  2. Menu Extensions › Apps Script. Efface le code présent et colle celui-ci :
  3. En haut du code, remplace change-moi par ton mot de passe, puis Enregistrer.
  4. Déployer › Nouveau déploiement, type Application Web. Exécuter en tant que : moi. Qui a accès : Tout le monde. Puis Déployer et autorise l’accès (Google prévient que l’appli n’est pas vérifiée : Paramètres avancés › Accéder au projet).
  5. Copie l’adresse de l’application Web (elle finit par /exec), colle-la ci-dessus avec ton mot de passe, puis Vérifier.
  6. Va dans Les mots et touche Enregistrer dans l’appli : la feuille reçoit la liste actuelle.

Les téléphones envoient seulement des comptes : une partie lancée, une envie proposée, un kiff kiff, un « on passe », et pour une envie le mot de chaque roue. Jamais de prénom ni de texte écrit à la main.
