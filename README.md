# Kiff Kiff

Jeu à deux sur un téléphone : trois rouleaux de machine à sous composent une phrase d’envie (« J’ai envie que tu me gratouilles le gros orteil en chantonnant »). L’un·e propose, l’autre peut changer une roue, et rien ne se passe tant que les deux n’ont pas dit « j’ai envie ».

Jouer : https://vernetmarc-glitch.github.io/roue-du-consentement/ (Red Corner, piment Tendre + Pimenté par défaut)

Ouvrir directement une ambiance :
- Arty : https://vernetmarc-glitch.github.io/roue-du-consentement/?design=arty
- Pomme d’Amour : https://vernetmarc-glitch.github.io/roue-du-consentement/?design=pomme
- Red Corner : https://vernetmarc-glitch.github.io/roue-du-consentement/?design=redcorner

Régler le piment dans le lien : `&piment=3` (Brûlant seulement), `&piment=123` (tout), etc.

Le fonctionnement complet est décrit dans [BRIEF.md](BRIEF.md). Pour changer les mots des roues, modifier `data.js`.
