# Kiff Kiff

Jeu à deux, sur un téléphone ou sur deux : trois rouleaux de machine à sous composent une phrase d’envie (« J’ai envie que tu me gratouilles le gros orteil en chantonnant »). L’un·e propose, l’autre peut changer une roue, et rien ne se passe tant que les deux n’ont pas dit « j’ai envie ».

Jouer : https://kiff-kiff.fr/ (Red Corner, piment Tendre + Pimenté par défaut)

Ouvrir directement une ambiance :
- Arty : https://kiff-kiff.fr/?design=arty
- Pomme d’Amour : https://kiff-kiff.fr/?design=pomme
- Red Corner : https://kiff-kiff.fr/?design=redcorner

Régler le piment dans le lien : `&piment=3` (Brûlant seulement), `&piment=123` (tout), etc.

Pour jouer chacun·e sur son téléphone : à l’écran « Qui joue ? », choisir « L’autre joue… sur son téléphone », puis faire scanner le QR code à l’autre.

Pour l’installer sur Android : ouvrir le lien dans Chrome, puis « Installer l’appli » sur l’accueil (ou menu ⋮ > « Ajouter à l’écran d’accueil »).

L’atelier (statistiques des parties et mots des roues) : https://kiff-kiff.fr/atelier/

Le fonctionnement complet est décrit dans [BRIEF.md](BRIEF.md). Pour changer les mots des roues, modifier `data.js`.
