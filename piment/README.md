# Variante « piment » — à affiner

Branche `piment`. Jouable sur https://vernetmarc-glitch.github.io/roue-du-consentement/piment/ (copie déployée dans le dossier `piment/` de la branche principale). Le jeu principal n’est pas modifié.

## Ce qui change

- **Niveau de piment 1, 2 ou 3** : sur l’accueil (trois piments à choisir, avec une phrase qui décrit le niveau) et dans le jeu (bouton piments dans la barre du haut, qui ouvre la même fenêtre). Il vaut pour toutes les ambiances.
- Un niveau montre aussi tout ce qui est en dessous. Le niveau se règle pendant la composition ; pendant la réponse, il est bloqué pour ne pas changer la proposition dans le dos de l’autre.
- Le niveau reste mémorisé sur le téléphone, et se passe dans le lien : `?piment=1`, `2` ou `3` (combinable : `?design=redcorner&piment=2`).
- Les manières peuvent changer avec le sens de la phrase : « que tu me … avec **ton** sexe » / « de te … avec **mon** sexe ».
- **Red Corner devient le Red Corner du Nostra, soirée Décadanse** : logo « Kiff Kiff au Nostra », enseigne « Red Corner » au néon rouge sur l’accueil, « Kiff Kiff » sur une ligne, reflets de boule à facettes qui glissent sur le velours, « au Red Corner du Nostra » sur la célébration.

## Contenu par niveau (proposition v2)

**Niveau 1 — Tendre** : tout l’existant, sauf ce qui monte aux niveaux 2 et 3.

**Niveau 2 — Pimenté** (estampillé de 2 piments dans les roues)
- Depuis l’existant — actions : sucer, déglinguer ; endroits : le fessier, le téton gauche ; manières : sans vergogne, avec gourmandise, comme un·e sauvage.
- Ajouts — actions : lécher, mordre, dévorer, fesser, faire un suçon sur, mettre un glaçon sur, enduire d’huile, verser du chocolat sur, frotter ; endroits : les tétons, l’intérieur des cuisses, le creux des reins, le bas du ventre, les lèvres, les poignets ; manières : goulûment, en twerkant, du bout des lèvres, les yeux dans les yeux, les yeux bandés, avec ta/ma langue, avec de l’huile, en gémissant doucement, avec un glaçon dans la bouche.

**Niveau 3 — Brûlant** (estampillé de 3 piments)
- Depuis l’existant — actions : introduire un appendice dans, circlure ; endroits : le sexe.
- Actions : laper, écarter, attacher, téter, branler, doigter.
- Endroits (que tout le monde a, quel que soit son sexe) : l’entrejambe, le pubis, le périnée, la raie des fesses, l’anus, le point le plus sensible, tout ce qui dépasse.
- Manières : comme un·e bon·ne petit·e chien·ne, en mode soumis·e, en mode dominant·e, avec ton/mon sexe, avec tes/mes tétons, à genoux, en me/te tirant les cheveux, jusqu’à ce que je supplie / tu supplies.

Nombre de cases (actions / endroits / manières) : niveau 1 = 21 / 21 / 20, niveau 2 = 32 / 29 / 32, niveau 3 = 40 / 37 / 40.

## Estampille

Dans les roues, chaque case pimentée porte une petite pastille à 2 piments, chaque case brûlante une pastille à 3 piments, visible aussi pendant que la roue tourne. Les lecteurs d’écran entendent « pimenté » ou « brûlant » après la case.

## Pour réintégrer dans le jeu principal

Fusionner la branche `piment` dans `main`, puis supprimer le dossier `piment/` de `main`.
