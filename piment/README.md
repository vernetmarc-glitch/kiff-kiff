# Variante « piment » — à affiner

Branche `piment`. Jouable sur https://vernetmarc-glitch.github.io/roue-du-consentement/piment/ (copie déployée dans le dossier `piment/` de la branche principale). Le jeu principal n’est pas modifié.

## Ce qui change

- **Niveau de piment 1, 2 ou 3** : sur l’accueil (trois piments à choisir, avec une phrase qui décrit le niveau) et dans le jeu (bouton piments dans la barre du haut, qui ouvre la même fenêtre). Il vaut pour toutes les ambiances.
- Un niveau montre aussi tout ce qui est en dessous. Le niveau se règle pendant la composition ; pendant la réponse, il est bloqué pour ne pas changer la proposition dans le dos de l’autre.
- Le niveau reste mémorisé sur le téléphone, et se passe dans le lien : `?piment=1`, `2` ou `3` (combinable : `?design=redcorner&piment=2`).
- Les manières peuvent changer avec le sens de la phrase : « que tu me … avec **ton** sexe » / « de te … avec **mon** sexe ».
- **Red Corner devient le Red Corner du Nostra, soirée Décadanse** : logo « Kiff Kiff au Nostra », enseigne « Red Corner » au néon rouge sur l’accueil, ligne « Soirée Décadanse », reflets de boule à facettes qui glissent sur le velours, « au Red Corner du Nostra » sur la célébration.

## Contenu par niveau (proposition)

**Niveau 1 — Tendre** : tout l’existant, sauf ce qui monte au niveau 2.

**Niveau 2 — Pimenté**
- Déplacés depuis l’existant — actions : sucer, déglinguer, circlure, introduire un appendice dans ; endroits : le sexe, le fessier, le téton gauche ; manières : sans vergogne, avec gourmandise, comme un·e sauvage.
- Ajouts — actions : faire un suçon sur, mettre un glaçon sur, enduire d’huile, verser du chocolat sur, frotter ; endroits : les tétons, l’intérieur des cuisses, le creux des reins, le bas du ventre, les lèvres, les poignets ; manières : en twerkant, du bout des lèvres, les yeux dans les yeux, avec de l’huile, en gémissant doucement, avec un glaçon dans la bouche.

**Niveau 3 — Brûlant**
- Actions : lécher, laper, mordre, dévorer, fesser, écarter, attacher, téter, branler, doigter.
- Endroits (que tout le monde a, quel que soit son sexe) : l’entrejambe, le pubis, le périnée, la raie des fesses, l’anus, le point le plus sensible, tout ce qui dépasse.
- Manières : goulûment, comme un·e bon·ne petit·e chien·ne, en mode soumis·e, en mode dominant·e, avec ton/mon sexe, avec tes/mes tétons, avec ta/ma langue, les yeux bandés, à genoux, en me/te tirant les cheveux, jusqu’à ce que je supplie / tu supplies.

Nombre de cases (actions / endroits / manières) : niveau 1 = 21 / 21 / 20, niveau 2 = 30 / 30 / 29, niveau 3 = 40 / 37 / 40.

## Pour réintégrer dans le jeu principal

Fusionner la branche `piment` dans `main`, puis supprimer le dossier `piment/` de `main`.
